# On-site search results (/locations?search=…) are kept out of the index by a
# `noindex,follow` robots meta tag, set in src/pages/Locations.tsx whenever the
# URL carries a query string.
#
# The Disallow rules below are STAGED, NOT ACTIVE. Do not uncomment them yet.
#
# Why: robots.txt blocks crawling, not indexing. Disallowing these URLs stops
# Googlebot fetching them, which means it can never read the noindex tag. A
# search URL that is already indexed would then be frozen in place and can
# persist as a URL-only result indefinitely. The noindex has to be crawled and
# processed FIRST; the Disallow is what stops new parameter combinations from
# being crawled afterwards.
#
# UNCOMMENT WHEN, AND ONLY WHEN, THIS IS VERIFIED:
#   /locations?search=elk%20grove no longer appears as indexed in Google Search
#   Console's Pages report. Inspect the URL directly; "Excluded by 'noindex'
#   tag" is the state you are waiting for.
#
# Verify it — do not enable on a date or a guess. Enabling this while the URL is
# still indexed recreates exactly the problem the noindex was added to solve.
#
# The rules are repeated per user-agent group on purpose. Crawlers obey only the
# single most specific group that matches them, so a rule placed solely under
# `*` would be invisible to Googlebot and Bingbot, which have their own groups.

User-agent: Googlebot
Allow: /
# Disallow: /locations?*search=

User-agent: Bingbot
Allow: /
# Disallow: /locations?*search=

User-agent: Twitterbot
Allow: /

User-agent: facebookexternalhit
Allow: /

User-agent: *
Allow: /
# Disallow: /locations?*search=

# Discovery on this site depends on the sitemap more than most.
#
# The app is client-rendered, so the pre-JS HTML every URL returns contains a
# single internal link. A crawler's first pass therefore finds almost no link
# graph to follow, which makes sitemap.xml the primary discovery mechanism
# rather than a supplement to crawling. Without this directive, Google finds it
# only if someone submitted it in Search Console.
#
# The file is regenerated at build time by the sitemapPlugin in vite.config.ts.
